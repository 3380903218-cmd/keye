## 下载

视频、课堂音频和大型栅格文件通过 Git LFS 保存。完整取得这些文件需先安装 Git LFS，然后运行：

```sh
git lfs install
git clone https://github.com/3380903218-cmd/keye.git
cd keye
git lfs pull
```

部分文件为相对符号链接；使用支持符号链接的 Git 环境可保留原目录之间的跳转。

# 进展gephi数据集：数据字典

版本2026-10-13-v1。主研究单位为**有来源定位的取得／存放／接收事件**；主图单位为相同转出、接收主体的聚合关系。全部CSV为UTF-8 BOM，逗号分隔。表内多值字段用分号连接。空白为未知或未记录，不等于零。

## 权威输入与派生文件

权威输入为entities、events、event_evidence、event_participants、quantities、sources、literature_coverage、context_only、legacy_mapping和gaps这十张CSV。nodes、edges、node_metrics及GEXF由rebuild.py生成。请修改权威输入后重建，不要同时维护两个互相冲突的版本。

稳定键：实体用N前缀，事件用DH，证据用EV，参与行用P，数量行用Q，背景用CTX，来源沿用项目S编号。Id是机器键，Label是显示名称。

## entities.csv：实体登记

| 字段 | 类型 | 定义 |
|---|---|---|
| Id | 字符串，唯一 | 实体稳定键；沿用旧ID时说明语义修订 |
| Label / LabelEN | 字符串 | 中文显示名及英文／法文名 |
| NodeType | 分类字符串 | Person人物、Expedition考察队、Institution接收机构、Government政府机构、SourceSite来源地点；辅助图另有Event |
| Place | 字符串 | 地点属性，不是地理坐标，也不额外制造城市节点 |
| HistoricalPolity | 字符串，可空 | 当时机构或行动相关政治背景；不是未核人员国籍 |
| Role | 字符串 | 已记录角色；不等于某一事件中的交接角色 |
| Alias | 多值字符串 | 人名、旧称、转写别名；不能单靠相似名字自动合并 |
| SourceRef | 多值字符串 | 定义该实体的来源ID |
| Core | 整数0/1 | 1表示本版主体交接主图节点；不是重要性等级 |
| Notes | 字符串 | 实体边界、机构沿革和未知项 |

历史节点N007为British Museum，N009为京师图书馆，N014为当时巴黎国立图书馆；现代名称不反推为1900年代交接主体。N008旧抽象清政府节点不继续进入本包主图。

## events.csv：事件权威表

| 字段 | 类型 | 定义 |
|---|---|---|
| EventId | 字符串，唯一 | 一次取得阶段或一次可区分的接收批次 |
| Label | 字符串 | 事件的简明名称 |
| Source / Target | 字符串外键 | 转出／接收主体的实体Id；不是文献作者与被提及者 |
| Type | 固定字符串 | Directed |
| Weight | 数值 | 固定1，每行一个记录事件；不按物件数量加权 |
| Route | 分类字符串 | Stein、Pelliot、Qing；研究路线归组，不是完整旅行轨迹 |
| Relationship | 分类字符串 | acquisition取得；physical_deposit实物存放；institutional_receipt机构接收；sample_submission样本送呈；supplementary_receipt续交接收 |
| YearStart / YearEnd | 整数 | 年精度或不确定日期的界限，不能当持续保管区间 |
| DateDisplay | 字符串 | 人可读的日期和精度限制；包含必要的派生换算说明 |
| DateOriginal | 字符串 | 保留原来源日数、纪年或相互不同的日期表述 |
| CalendarOriginal | 分类字符串 | Gregorian或Qing_lunisolar；不得把清历月日直接当公历 |
| DatePrecision | 分类字符串 | month、month_conflicting_days、year、year_end、year_range、year_inferred、year_with_terminus、day_from_transcription_calendar |
| DateBasis | 字符串 | 哪份文献、哪页支持日期；包括回推、换算和上下界的理由 |
| EventConfidence | 分类字符串 | 事件判断等级；本版为medium，有出处但保留来源限制 |
| DateConfidence | 分类字符串 | 独立于事件等级；本版为medium或low |
| EvidenceStatus | 分类字符串 | 来源获取与证据性质的状态，不是概率 |
| SourceRef | 多值字符串 | 全部用于本事件的来源ID；必须在证据表逐项闭合 |
| QuantitySummary | 字符串 | 人可读的数量口径；标量与单位见quantities |
| QuantityConflict | 字符串 | 不同版本、范围与单位的差异，以及禁止的加总 |
| EventGroupId | 字符串 | 相关取得阶段或接收组；同组不自动合并为一次事件 |
| LegacyId | 多值字符串，可空 | 旧试点记录；完整处置见legacy_mapping |
| Notes | 字符串 | 事件界定及未确认环节 |

`documented_participant_account`为参与者后出自述；`documented_deposit_date_bounded`为存放已述、时间仅有限界；`documented_participant_and_institution`为参与者与机构叙述；`institutional_retrospective`为机构回顾；`archival_transcription_only`为研究文章中的档案录文，本次未取得原件影像。

medium不表示事件“只有50%发生”；它标注仍需原档、日期或对象级核验。没有将本包关系标成high，也不将评级当作数值边权。

## nodes.csv / edges.csv：主图派生表

nodes继承实体字段，另有：

| 字段 | 类型 | 定义 |
|---|---|---|
| GraphView | 字符串 | actor_transfer_aggregated |
| InLinks / OutLinks | 整数 | 聚合邻接边的入度与出度 |
| Degree | 整数 | InLinks＋OutLinks；本版最大2 |
| RecordedEvents | 整数 | 作为转出／接收端关联的不同事件数，不含纯参与角色 |
| Route | 多值字符串 | 该节点涉及的研究路线；共享节点可有多值 |

edges的关键字段：

| 字段 | 类型 | 定义 |
|---|---|---|
| Id | 唯一字符串 | L_Source_Target，按有向主体对生成 |
| Source / Target / Type | 字符串 | 对应nodes.Id；Directed |
| Weight | 数值 | 固定1，等权邻接；6条边权重合计6 |
| Label | 字符串 | n个记录事件，用于显示 |
| EventCount | 整数 | 相同主体对关联的独立记录事件数；全图合计9 |
| EventIds | 多值字符串 | 映射至events.EventId；原事件逐行保存 |
| Route / Relationship | 多值字符串 | 聚合范围内出现的路线和关系类型 |
| YearStart / YearEnd | 整数 | 组内最早与最晚事件年界限，不是持续关系时间 |
| SourceRef / EvidenceIds | 多值字符串 | 组内来源与证据行集合；不是独立佐证次数 |
| Confidence | 字符串 | 组内存在medium则为medium；不平均评级 |
| DateNotes | 字符串 | 各成员事件日期说明，保留不确定性 |
| GraphView / Notes | 字符串 | 视图及解释规则 |

聚合键为(Source,Target)，不同取得阶段保留EventId；目前每个主体对仅涉及一条路线。若以后同一主体对跨多个路线，分路线图应改为对筛选后的events重新聚合，以免带入另一条路线的EventCount。

## event_evidence.csv：证据链

| 字段 | 定义 |
|---|---|
| EvidenceId | 唯一证据行键 |
| RecordId | 事件DH或背景CTX键 |
| SourceID | sources外键 |
| Locator | 印刷页／PDF页／段落，注明具体版本；页码都从1开始 |
| ExcerptOriginal | 短原文摘录／扫描人工转录；S25为历表对照关系的文字转写 |
| ParaphraseZH | 中文转述，不能替代原文定位 |
| SupportFor | 本行支持的字段或判断，例如endpoints、date、roles、quantity_conflict；不意味着引文单独支持全部事件属性 |
| EvidenceNature | 参与者回顾、近同时自述、研究者转引、机构回顾、档案转录或历表 |
| Dependency | 是否依赖同一日记、书信、转载；防止将转引数量当独立证据 |
| Verification | local_full_text、scan_checked等核验方式；不表示档案原件已核 |
| Limitation | 明确该证据尚不能证明什么 |

## event_participants.csv与辅助图

ParticipationId为唯一行键，EventId与EntityId为外键，Role记录具体行为，SourceRef与Locator支持角色，Notes保留限制。同一参与者在同一事件的多个角色放在一行分号连接，不重复计为多个移交。

辅助节点中Bipartite=0为主体，=1为事件，GraphView=entity_event_incidence。辅助边Role=transfer_from或transfer_to时只表达事件关联端点；其他角色表达人对事件的参与。辅助图的Degree是关联度，不能与主图Degree混用。

## quantities.csv：数量版本

| 字段 | 定义 |
|---|---|
| QuantityId / EventId / SourceID | 数量行键与事件、来源外键 |
| Value | 来源记数的非负数值；不自动成为精确事实 |
| Comparator | reported原文记数、approximate约数、greater_than下界表述 |
| Unit | bundles捆、cases箱、scrolls卷、bound_fragment_volumes粘片本；单位不能直接相加 |
| Material | 数量所指材料类别 |
| Coverage | 分项、替代版本、批次总括、伴随艺术品或既有样本返还等计数范围 |
| Locator / Notes | 定位与冲突、范围限制 |

13／20捆和220／230捆是同一事件的不同来源口径，不累计成额外事件；DH004存放数量是前段取得的后续叙述，不能再加到总取得量。DH009返还样本不算新增收藏。

## 来源与审计表

sources中SourceID为唯一键；Author、Year、Title、Citation、URL和DOI是书目登记；LocalPath相对于DunHuang Project；Status是实际获取状态；EvidenceType为来源性质；VersionGroup将同研究版本关联；UsedInCore标注是否用于主事件；Limitation保留限制；SHA256是当前本地文件内容身份。没有本地全文的来源仍可登记，但不得作为新增事件的全文证据。

literature_coverage的Disposition区分main_evidence、duplicate_version、context_or_archive_navigation、background_outside_transfer_unit、metadata_or_unavailable_not_event_evidence；CheckedScope明确本次检查范围。背景论文没有进入主图，并不表示其研究价值低。

context_only中MainGraphIncluded固定0；未知Target可空且不导入Gephi。legacy_mapping逐条列旧ID、旧关系、Action、新RecordId与Reason。gaps中的GapId、Route、MissingRelationOrFact、Reason、AvailableSources、NextEvidenceNeeded和EffectOnAnalysis用于后续补证，不能把缺口当零事件。

node_metrics是主图度数与事件关联数的只读快照；子图需重新计算其本地度数。run-manifest与validation_report分别记录计算运行和数据校验，均不能代替历史解释。

# 清历日期换算记录

核对日期：2026-10-13（新加坡时间）。原日期来自S19档案录文，而非本次取得的档案原件。

香港天文台1910历表的公历12月行：12月2日为农历十一月初一；12月13日对应十一月十二；12月15日对应十一月十四。已下载PDF并用PDFKit渲染，逐列目视核对。

因此宣统二年十一月十二日学部行文可规范为1910-12-13，十一月十四日底账日期可规范为1910-12-15。换算字段是研究者派生值，事件原始日期仍逐字保留；历表不能证明底账转录无误。

S19后文将这些日期写作“1910年11月12日／14日”，本包不沿用该写法。主批18箱只知行文前已取运，不把该行文日当成主批接收日。

来源：[香港天文台1910对照表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/1910.pdf)。

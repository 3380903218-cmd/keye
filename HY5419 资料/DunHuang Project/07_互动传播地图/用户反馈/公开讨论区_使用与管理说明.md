# 公开讨论区：使用与管理

版本：2.9.1，2026年11月3日。数据库与留言接口已部署并通过实际保存、读取、回复、刷新和隐藏留言核验。

## 访客怎样使用

中文入口：https://3380903218-cmd.github.io/dunhuang-in-motion/?lang=zh#discussion
英文入口：https://3380903218-cmd.github.io/dunhuang-in-motion/#discussion

讨论区位于“史料与方法”之后，页脚也有“读者讨论”入口。填写昵称、选择相关板块并输入内容，即可发表；不需要注册或登录。其他访客能公开阅读，点击一条讨论下的“回复”即可交流。“刷新”用于读取后来发表的内容。

可以使用任何语言留言或回复。中英文切换只改变界面文字，不翻译读者自己的留言；从右向左书写的内容按其文字方向显示。昵称是自行填写的，不代表已核实的身份；讨论区内容与经过核查的历史证据分开。

## 你怎样管理留言

登录自己的 Supabase 账号后，打开：
https://supabase.com/dashboard/project/qtuxpxccweapkqeoaata/editor

1. 在表格编辑器选择 `discussion_private` schema，再打开 `messages` 表。
2. `display_name` 是昵称，`body` 是内容，`created_at` 是服务器记录的发表时间。`parent_id` 为空的是主帖，有值的是回复，指向主帖的 `id`。
3. 遇到不适合公开的留言，把该行 `hidden` 改为 `true` 并保存。隐藏主帖后，下面的回复也会从公开页面消失。需要恢复时改回 `false`。优先使用这个可恢复的操作。
4. 确定要永久删除时，才删除行。删除主帖会连同它下面的回复一起删除。
5. 需要整理同学反馈时，可从表格菜单导出 CSV。导出的原始留言保存在自己的资料中，不应直接加入公开网站仓库。

当前版本不提供访客自行编辑或删除已发表留言。你可以在讨论区用自己的昵称回复，但网站不会把这个昵称标为已经认证的管理员。

## 费用、访问与维护

使用你个人组织中的 `dunhuang-discussion`，地区为新加坡，创建时确认为 Free 方案，报价为每月 0 美元；未升级付费方案。免费额度与平台政策仍应以后台为准。

免费项目可能因长时间不活动暂停。展演前打开网站试读留言；若项目暂停，在 Supabase 控制台恢复项目后再测试。不要为恢复而盲目升级付费方案。

留言需要联网。离线 HTML 保留地图、关系网络和原有下载资料，并提供前往在线讨论区的链接。地图与 Gephi 网络的初始化不依赖留言服务。

原网站此前已有家人的国内网络访问反馈；新增 Supabase 留言服务还没有做国内网络实测。可把中文讨论入口发给国内朋友，分别确认能否读取、发表和回复。

核验使用的临时留言已清理。正式留言保存在云端，不只保存在访客浏览器。

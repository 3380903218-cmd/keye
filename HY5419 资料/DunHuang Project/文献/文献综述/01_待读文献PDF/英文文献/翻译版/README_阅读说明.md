## 怎样阅读和记录

- 每组先呈现英文原文，再呈现对应中文。英文直接取自原PDF页面，保留原有字形与符号；较长或跨页的段落可能分成连续的小段。
- 编号如`G13-P106-007`表示G13文献、原PDF第106页、该页的第7组文本，方便回查。
- 使用PDF的目录／书签，可跳到对应原PDF页码；正文同时标明可确认的原刊、书内或章内页码。
- **做正式引用时，使用原刊或书内页码。**译稿底部页码只用于在这份对照稿中导航，不能替代原文页码。
- 每份PDF末尾的“原页核对附录”收录本次翻译范围的完整原页，包括图像、表格、公式、注释和参考文献。公式、数值密集区和非叙述编号主要保留原版，并配中文说明；核对数式、表格和原文上下文时请查看附录。
- 人名、机构名、藏品编号、外文书目题名及部分非英语术语可能保留原文。中文中的“原文注号”对应原文脚注／尾注编号。

# 阅读顺序与用途

整理日期：2026-10-27。PDF已经集中在[01_待读文献PDF](../01_待读文献PDF/)，已按正文语言分为[中文文献（5份）](../01_待读文献PDF/中文文献/)和[英文文献（7份）](../01_待读文献PDF/英文文献/)。文件名前的01–12是建议阅读次序；无需从头通读每一本。


英文文献的[英中逐段对照译稿及阅读说明](../01_待读文献PDF/英文文献/翻译版/README_阅读说明.md)已完成：5篇论文全文、两本书的重点章节；这些是原文的阅读副本，不新增文献条目。
先读潘晟第一节、2012论文集的两章和王冀青2020，明确取得、交涉与消息传播的问题；读Faust前先读G01的关系编码部分。三篇含批注的文件原样保留。

`make_bilingual.py`从原PDF提取带页码与位置的文字段落作为翻译输入。英文对照区域直接嵌入原PDF的对应区域，以保留字形、符号与原有内容；附录还保留翻译范围内的完整原页。中文译文紧接对应英文，每组使用固定段落编号。双栏按栏排序；长段落或跨页段落接续显示。非叙述数式、表格数值及页边非正文内容不强行翻成叙述文字，原版见附录。

翻译使用本机运行的腾讯Hy-MT2系列模型（7B与1.8B）。初译使用题名、相邻原文与术语表；针对段落对应问题，874组文本已按单段原文独立重译，避免相邻语境被混入本段译文。模型和运行程序均来自官方发布，文件校验记录另存。原文未发送到公开在线翻译接口。最初使用Hy-MT1.5小模型的试译在人名指代上出现错误，已弃用并重新翻译，没有作为最终交付。Hy-MT2模型结果也属于辅助阅读译稿，不代表逐句人工审定；重点校读范围以修订文件为准。

`*_source.json`：来源文件、哈希、范围、段落位置、翻译输入和不另译项目。

`*_translations.jsonl`：可续接的模型译文记录。最终采用的重点校读修订优先取自 `reviewed_corrections.json`；仅检查JSONL无法还原最终修订。

`reviewed_corrections.json`：重点校读后的替换译文，覆盖若干摘要、结论及概念段落；不是逐句人工审定记录。

`*_review_flags.json`：数值保留、非中文片段等自动复核提示。书目、编号、数式与中文数词可产生提示，提示不等于已确认错误。

`*_output.json`及最终核验记录：交付PDF的页数、范围、段落对应数量与哈希。只有实际完成的交付才算完成，不以中间日志中的“PDF READY”代替最终核验。

本目录为制作记录，不是新增待读文献。模型权重与样页渲染放在临时目录，没有混入待读PDF文件夹。

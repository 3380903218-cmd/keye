## 已找到、但需要谨慎编码的内容

**英国路线的日期与重复问题。** S07原825页给出一次总括性的存放表述，现有E004/E007均用它作依据。S17的AAM第16页提供1909年抵英的研究叙述，注61明确区分当时的材料状态与正式入藏。S03还有1908年装箱和1909年拆箱的线索。这些材料足以启动日期与事件类型修订，但尚不能提供精确的博物馆接收日，更不能证明两次独立入馆。S07原916页提及1910年送巴黎编目的材料，属于Stein材料的后续移动，应与Pelliot自己取得的材料分开。

**北京路线已取得接收底账的研究转录。** S19转录了学部拨送文件和京师图书馆接收底账。前者追述18箱已取运，并列续送；后者记续送22卷和粘片2本。原文日期分别写作“宣统二年十一月十二日”和“宣统[二]年[十一]月[十四]日”。目前尚未取得档案影像并完成历法核验，不能直接录成公历`1910-11-12`和`1910-11-14`。首批18箱与续交不是同一批；样本一卷的流转解释须区分作者推论和账面原文。S21考察报告的相关叙述不能算另一份独立接收原件。

**数量差异要保留版本。** S03印刷73页注24并列追加取得的日记13捆与后出叙述20捆；注26并列安西220/230捆和不同日期记录。下一步应记录每个数字出现在哪份文件、描述什么动作，不宜仅挑一个数字或把日期差异拆成新事件。

**接收机构和现代馆藏数量需要分开。** [S12早期编目文章](full-text/S12_NLC_2020_敦煌整理与编目.html)有助于落实京师图书馆及参与编目的人员；[S13馆藏整理文章](full-text/S13_NLC_2025_馆藏敦煌文献.html)说明1910年运京与后续入藏的区别。现代馆藏编号数不宜填入1910年的运输数量。

## 文件说明与复核方式

- `full-text/`：可阅读的PDF或HTML正文快照。HTML用浏览器打开；外链图片和样式不保证离线完整，正文另存于`extracted/`。
- `extracted/`：PDF文本层或网页文字提取，适合检索。它们不是校勘文本，仍可能有断行、字形和排版问题。S07/S22为扫描PDF，无可搜索文字层；原有Stein OCR可辅助检索，引用以扫描为准。
- [扫描页码对照.csv](扫描页码对照.csv)：区分印刷页、本地PDF页和机构扫描序号。扫描文件名不能直接当作书页号。
- [检索记录.csv](检索记录.csv)、[筛选与缺口.csv](筛选与缺口.csv)：保留9批、46项搜索/打开/定位动作及取舍。原始工具结果在`sources/search_*.json`；下载结果、校验值、失败响应和PDF合成依据也在`sources/`。
- `sources/scan-images/`保留原始JPEG，包括检索时下载的相邻页。仅选定的已核对关键页进入Stein阅读摘录；其他原图不表示已经精读或用于证据判断。
- [文件校验清单.csv](文件校验清单.csv)与[sources/最终校验.json](sources/最终校验.json)记录文件存在、哈希及关联校验；6份本轮PDF及2份复用PDF均能解析页数，两份合成PDF已抽查渲染与关键页。PDF文本解析曾出现一条通用CoreGraphics警告，未出现页面解析失败；这不代表每页字体与图像均已逐一视觉验收。

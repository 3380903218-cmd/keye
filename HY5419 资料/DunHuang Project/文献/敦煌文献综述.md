# 斯坦因、伯希和与敦煌第17窟文献流通：一份面向数字史项目的文献综述

## 1. 范围与检索方法

本文围绕三个问题组织材料：第一，第17窟（通常称“藏经洞”）究竟是什么性质、何时封藏；第二，1900年发现后，王圆箓、斯坦因、伯希和以及清政府如何参与文献的取得和转移；第三，如何把这些不完整、互相带有立场的叙述转化为可追踪的数字史数据。检索以 Google Scholar 为发现入口，再回到 Persée、British Library repository、Brill、开放 DOI 仓储、Silk Roads Archaeology and Heritage 和 Internet Archive 核对出版身份与全文。已下载的开放全文和 Stein 的原始资料包均保存在本目录；伯希和 1908 年报告和 Imaeda 2008 年论文则保留了官方访问路径，详见《敦煌文献检索与下载记录.md》。

## 2. 藏经洞的性质与封藏问题

Rong 与 Hansen 将第17窟放在“文献库”“宗教性废弃物储藏处”和寺院空间变迁的交叉问题中讨论，指出文献年代、洞窟用途和封闭原因不能由一个简单故事解释（Rong and Hansen 1999: 247-275）。Stein 在《Serindia》中依据有纪年文书和缺少西夏文字的反向证据，把最终封藏大致放在11世纪初，并提出其中相当一部分是从寺院和佛教活动中清理出的“sacred waste”（Stein 1921: 820-821）。伯希和也根据文书纪年提出相近的年代判断，但他把封闭与西夏征服联系起来；这一解释在后来的研究中并没有成为无争议共识。

因此，对数字史项目而言，“原始图书馆”不应当直接作为一个已证实的数据库字段。更稳妥的做法是把“文献形成”“寺院使用”“捆束/堆放”“封藏”“1900年后重新整理”分别建模，并为每个阶段保存证据和不确定性。第17窟包含汉文、藏文以及其他语言的文书、绘画、纺织品和印刷品；它既是一个物质储藏空间，也是后世不断赋予新意义的文化遗产空间。

## 3. 王圆箓与1900年前后的地方流通

Doumy 的贡献在于把王圆箓从“被动看守者”或单纯“卖出国宝的人”重新放回事件中心。王圆箓在1900年发现洞窟后，向地方官员报告并长期控制出入口；地方官员、寺院僧侣、信众和捐款网络共同构成了文献在敦煌地方社会中的流通环境（Doumy 2025: 821-845）。S01/S02 还指出，王圆箓在斯坦因到来前很可能已经打开、移动、赠送、筛选和重新捆扎部分物品。Terzi 与 Whitfield 根据斯坦因的日记、照片、编号和捆束记录，进一步说明斯坦因看到的是1907年经过重新安排的状态，而不是1900年打开瞬间的“原始现场”（Terzi and Whitfield 2024: 56-76）。

这一点改变了“王圆箓发现 - 外国探险者拿走”的单线叙事。王圆箓的选择性开放、对佛经捆束的保留、对不同访客的不同谈判，以及地方僧侣和赞助者对修缮经费的期待，都影响了哪些文献能够进入后来的海外收藏。换言之，地方社会不是转移路线上的空白地带，而是路径形成的第一个关键节点。

## 4. 斯坦因的取得、装箱与伦敦路径

Stein 的《Serindia》是目前最详细的一手叙述之一，但也是一份具有明显自我正当化色彩的探险者叙事。他把自己描述为把文献“救回”西方学术界，同时承认谈判、付款、秘密搬运和对捆束的快速筛选。1907年5月，他记录了约1,050个汉文“regular/library bundles”、80多个藏文卷包和11个大型藏文贝叶，并把含碎片、绘画、纺织品和非汉文材料的“mixed/miscellaneous bundles”与规整佛经捆束区分开来（Stein 1921: 821-823）。部分mixed bundles被王圆箓放在底部垫平地面，这说明洞窟中的位置已经受到了后来的重新利用。

Stein 的第一阶段交易发生在1907年5月至6月。按照《Serindia》的叙述，他取得约50包汉文、5包藏文以及从mixed bundles中挑出的物品，付款为四个马蹄银；文献在夜间被秘密搬到营地，离开敦煌时装为7箱文献和5箱绘画、刺绣及其他艺术品（Stein 1921: 823-825）。Terzi 与 Whitfield 将这组材料拆解为 Ac1a-Ac1d 等取得事件。第二阶段是1907年10月在安西取得的约220-230包文献；这批材料后来在和田重新编号、装箱，并随探险队的运输系统发往伦敦（Terzi and Whitfield 2024: 63-76）。Stein在《Serindia》中还写到，他在1914年从王圆箓保留的“储备”中又买得五箱中文卷轴（Stein 1921: 830）。

由此可将斯坦因路线暂时写为：

`第17窟/王圆箓的选择 -> 敦煌营地（1907） -> 安西取得第二批（1907） -> 和田编号与装箱（1908） -> 伦敦及相关英国收藏机构`

Terzi 与 Whitfield 的研究对数字建模尤其重要：斯坦因的编号可以帮助重建某些捆束内部的组合，但不能恢复洞窟整体原始排列。项目中应把“洞窟位置”“取得事件”“编号事件”“装箱事件”和“今日馆藏”作为不同字段，而不能用一个 Ch. 编号代表完整来源链。

## 5. 伯希和的筛选、巴黎路径与比较视角

伯希和在1908年3月3日至26日进入第17窟，约三周内在洞中快速检查大量卷轴；Stein 转述伯希和前十天每天约检查1,000卷，伯希和自己的报告则记录了他对非汉文、带纪年汉文和非佛教文书的选择标准（Pelliot 1908: 505-508；Stein 1921: 826-827）。他与斯坦因的专业背景不同，因此选择结果也不同：伯希和更重视语言多样性、文书年代和历史信息，对成套的汉文佛经捆束相对不感兴趣；王圆箓则对这些“regular”佛经更为看重，特别是对整齐的藏文贝叶有所保留（Doumy 2025: 833-840）。

伯希和带走的材料进入法国学术与收藏体系，相关文书后来与巴黎的国家图书馆、吉美博物馆等机构的整理、编目和出版相联系。这里需要区分“伯希和在现场选择”“离开敦煌后的运输”“进入具体法国机构”三个事件；如果没有逐件馆藏记录，不应把它们压缩成一条没有证据间隔的直线。伯希和的报告目前可以在 Persée HTML 直接阅读，PDF 受 Altcha 保护；因此综述引用一手报告时应注明使用的是官方 HTML 版本，而不是把未下载的 PDF 写成已保存全文。

## 6. 北京转运与再次分散

伯希和携带部分材料到北京后，清政府和中国学者逐渐意识到洞窟文献的重要性。1910年，中央政府下令把留在敦煌的文献运往北京保存（Doumy 2025: 821-822）。然而 Stein 在1914年回到敦煌时称，运输过程中的补偿款和看守并不可靠，文献在敦煌、肃州、甘州等地出现盗取和分散，另有一些流向新疆的地方官署和个人（Stein 1921: 829-830）。这段材料是回忆性的一手叙述，数量和具体责任仍需结合北京档案、地方文书和馆藏目录核查，但它足以证明“中央接收”并不是流通路径的终点。

因此，现代流散至少包含三个层次：王圆箓与地方网络造成的早期赠送、交易和隐藏；Stein、Pelliot 等探险者带来的跨国取得和重新编目；清政府运输及沿线再次盗散、地方留存和后续进入国家或海外机构的过程。把所有结果都称为“被外国人拿走”，既会遮蔽地方和国家节点，也会掩盖不同取得方式之间的差异。

## 7. 第17窟作为被不断重构的遗产空间

Zhou 把第17窟放进“漫长的20世纪”考察，强调它从宗教储藏空间逐渐变成艺术史对象和文化遗产展示空间。其时间线包括：1900年王圆箓发现；1907年Stein和1908年Pelliot进入；1941年张大千题记；1945年潘絜兹回应；1965年敦煌研究机构重新安置碑和造像；2000年将王圆箓修建的回廊改造成关于藏经洞的展览空间（Zhou 2024: 545-591）。这说明“第17窟”本身也有一条空间传播史：照片、题记、测绘、复制画、展览和数字图像共同塑造了公众今天所认识的藏经洞。

这条空间史与文献物理转移史应在数字项目中并列而非混合。可以分别建立 `物品流通网络` 和 `洞窟叙事/展示网络`，再通过时间和地点字段连接二者。Rong 2025 对敦煌文书所揭示的中古宗教、商业与文字网络的总结，可作为更长时段的背景，但不能替代1900年以后转运路径的证据。

## 8. 对数字史项目的建议与研究缺口

本组文献支持一个有争议但可操作的研究问题：**第17窟文献的“来源”究竟应由发现地点、取得者、运输者、现藏机构，还是由多重来源链共同定义？** 建议至少建立 Person/Institution、Place、Object/Manuscript/Bundle、Date、Event、AcquisitionType、PhysicalTransfer、CurrentHolding、LegalOwnership、CulturalClaim、DigitalReproduction、SourceRef、Confidence 和 UncertaintyNote 等字段。

每条边都应附 SourceID、正式页码或段落定位。例如“第17窟 -> Stein 1907敦煌营地”可以用 Stein 1921: 823-825；“安西 -> 和田编号装箱”使用 Terzi & Whitfield 2024 的 Ac2 和 Khotan 部分；“剩余文献 -> 北京 -> 沿线分散”使用 Stein 1921: 829-830，同时把“Stein的回忆性叙述”写入限制字段。Gephi 的中心性或地图上的线条只能表示资料中的连接强弱，不能直接被解释为责任、合法性或道德正当性。

当前最大的缺口有三类。第一，王圆箓在1900-1907年间具体赠送给地方官员、僧侣和访客的物品仍缺少完整清单。第二，北京接收、肃州/甘州沿线损失以及新疆官署留存的数量和馆藏对应关系尚未闭合。第三，Stein、Pelliot、俄国和大谷探险队的编号系统与今天各馆藏目录之间仍需逐件对接。下一步最有价值的工作不是继续堆叠宏大叙事，而是选择一小组文书或捆束，建立“物品 - 事件 - 地点 - 现藏 - 证据”五联记录，并把无法确定的环节明确可视化。
